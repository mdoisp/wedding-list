# Project Guidelines & Rules

## Commit Policy
- **Language**: All git commit messages MUST be written in English, without exceptions.
- **Format**: Conventional Commits standard (`feat(...)`, `fix(...)`, `chore(...)`, `ci(...)`, etc.).

## Workflow
- After completing each sub-task, commit and push to GitHub.
- Verify that the CI/CD pipeline on GitHub Actions completes successfully before proceeding to the next sub-task.
